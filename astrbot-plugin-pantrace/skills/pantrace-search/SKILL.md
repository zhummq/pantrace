# 盘迹网盘资源搜索

本 Skill 配合 `astrbot_plugin_pantrace` 插件使用。插件提供 `/搜` 命令真正执行搜索，本 Skill 提供对话层面的理解和引导。

## 平台与 key

搜索支持以下平台，用户说中文名时按下表对应：

| 中文 | key | 中文 | key |
|---|---|---|---|
| 夸克 | quark | 百度 | baidu |

## 引导用户搜索

当用户用自然语言表达"帮我找 XX 的网盘资源"时，直接用 `/搜` 命令帮他把关键词组织好，并提示他发送：

- 搜全部：`/搜 关键词`
- 指定平台：`/搜 关键词 夸克,百度`
- 翻页：`/搜 关键词 夸克 2`

如果用户只给了一个笼统的需求（比如"有没有好看的电影"），先追问具体的资源名、作者或版本号，再组织命令——搜索关键词越具体，结果越准。

## 结果解读

- 结果里的链接点击后会在网页打开一个过渡页，再自动跳转到网盘。**链接有时效**（默认 30 分钟），要提醒用户打开后先转存到自己的网盘。
- 显示"提取码"的平台，需要用户手动复制填写。
- 显示"缓存结果"表示这条是近期搜过的，不是新请求。
- 某平台没结果，可以换平台或不加平台筛选再搜一次。
- 若提示"IDR 签名已失效"，这是后端配置问题，告知管理员需要重新抓取签名写入后端 `.env`，普通用户重试无用。

## 边界

- 本 Skill 只做理解和引导，**真正的搜索由 `/搜` 命令完成**，不要声称自己能直接搜到结果。
- 不要编造任何网盘链接、提取码或资源标题。所有结果必须以插件返回的为准。
